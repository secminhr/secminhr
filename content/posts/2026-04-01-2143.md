最近碰到了一些和 accessibility 相關的事情，才特別去看相關的資源。

在視障方面，google 的 web.dev 在 [語意和螢幕閱讀器](https://web.dev/articles/semantics-and-screen-readers) 裡面是這樣說的（粗體是我認為重要的部分）：
> When we build graphical user interfaces, **we use CSS to add visual affordances** to our interface. For example, you might give a button a drop shadow and border so that it resembles an actual button in the real world.
> 
> But for users who are unable to see the screen, these visual affordances aren't conveyed to them. Therefore, you need to make sure that your interface is constructed in a way that can convey these same affordances to assistive technology. **This non-visual exposure of a UI element's affordances is called its semantics**.

在我加粗的部分其實是展示了這樣的關係：\
CSS $\underrightarrow{\text{\ \ \ \ creates\ \ \ \   }}$ visual cue\
Semantics $\underrightarrow{\text{\ \ \ \ creates\ \ \ \   }}$ non-visual cue

在這樣的想法下，為了 accessibility 所加上的說明或者 attribute 和 CSS 實際上有同樣的等級。
甚至，如果 CSS 被視為是某種附屬於 HTML 的東西的話（考慮 CSS 在除了 HTML 以外的 context 中無法發揮作用，一般來說），那麼 semantics 似乎是某種更基礎的東西，因為 semantics 有一部分是由 HTML 中使用的 tag 來決定的。
