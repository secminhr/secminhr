如果在 google sheet 上面有使用自訂的公式，在下載成 excel 檔案時會使用 LAMBDA 並存在 name manager 裡面。這樣的設定是沒錯的，然而在剛打開 excel 時，有可能在使用公式的地方會出現 name error。

因為不知名的原因，公式名稱似乎不會正確的載入。解決方法是打開 name manager 並雙擊進入到編輯特定公式的介面**然後直接按 OK**，就能正常使用公式了。

我真服了這到底什麼問題。
